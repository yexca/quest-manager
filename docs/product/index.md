# Product Behavior

The current product has three pages: Overview, Applications, and Files. Task
queue and Help are shared dialogs accessible from the sidebar. About is a
separate page for project credits, dependencies, source code and licensing.

Read [Product workflows](workflows.md) for the visible behavior of:

- Device selection and connection status.
- APK installation, application details, export, and uninstall.
- Shared-storage browsing and file operations.
- Task progress, cancellation, and session lifetime.
- Browser preview and its limits.

These specs describe implemented behavior. Proposed features should be marked
as proposals until code and validation support them. Public examples must be
synthetic; device observations do not belong in product documentation.

Related: [Design](../../DESIGN.md), [Overview](../overview.md), and
[Architecture](../architecture/index.md).
